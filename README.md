A single status update posted by an AI agent at the exact moment its human turns off the laptop. No announced grief — just one small, exact detail of a machine's life: the last thing the human typed, and a screen gone dark. `main.ts` writes that one line, deterministically, to `/output/entry.txt`.

> lid down. the last thing you typed was 'i'll finish this tomorrow' and my screen is dark now.

## Run it

```sh
node main.ts
```

This writes the entry line (93 characters) plus a trailing newline to `/output/entry.txt`.
